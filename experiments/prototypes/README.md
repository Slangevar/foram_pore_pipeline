# Prototype Archive

This folder contains exploratory clustering prototypes that are not part of the default production pipeline.

Archived prototypes:
- `prototype_hdbscan.py`
- `prototype_isomap.py`
- `prototype_shell_graph.py`
- `prototype_umap.py`
- `prototype_watershed.py`

Current production clustering entry point is `src/post_processing/prototype_tsne.py` (used by pipeline scripts).

Top-level names for archived prototypes are preserved as symlinks for compatibility.
