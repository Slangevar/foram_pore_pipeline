# Analysis Scripts

Utility scripts for post-run analysis and reporting.

- `calculate_stats.py`: Parses clean-job logs and exports outlier-removal statistics.
- `serve_html_folder.py`: Serves generated HTML visualizations from the cluster and prints SSH port-forwarding commands.
- `view_image_volume_python.py`: Opens a raw `.npy` image volume in a Python/matplotlib slice viewer and can export quick PNG previews.
- `visualize_image_volume_3d.py`: Creates a headless interactive Plotly HTML 3-D view of a raw `.npy` image volume for cluster use.
